# Implementation Plan — Platform Kos / Kontrakan / Rumah Sewa

**Version:** v0.1
**Status:** Draft
**Tanggal:** 2026-10-07
**Source:** Architecture Blueprint v0.1, PRD Blueprint v0.1, UX Blueprint v0.1, Product/Business Blueprint v0.2
**Target:** MVP Launch

---

## 1. Executive Summary

Dokumen ini memaparkan strategi dan tahapan implementasi teknis untuk membangun MVP platform penyewaan properti. Pendekatan yang digunakan adalah **Agile/Scrum**, dengan rilis bertahap untuk memastikan fondasi inti stabil sebelum fitur transaksional diimplementasikan.

---

## 2. Team Structure (Rekomendasi MVP)

Karena menggunakan arsitektur monolitik (CodeIgniter 4) yang terintegrasi penuh, tim dapat dioptimalkan menjadi:
- **1x Product Manager / UI/UX Planner** (Mengelola backlog & *wireframing*)
- **1-2x Fullstack PHP Engineer** (CodeIgniter 4, MySQL, Bootstrap/AdminLTE)
- **1x QA Engineer / Tester** (Bisa dirangkap oleh PM pada tahap awal jika *budget* ketat)

---

## 3. Implementation Phases (Milestones)

Estimasi total waktu pengerjaan MVP: **12 - 16 Minggu (6-8 Sprints @ 2 Minggu)**

### Phase 0: Project Setup & Foundation (Sprint 1)
**Fokus**: Infrastruktur awal, skema database, dan repositori CodeIgniter.
- [x] Setup repository (GitHub/GitLab) dan inisialisasi CodeIgniter 4.
- [x] Setup environment *hosting* cPanel (Development & Production).
- [x] Integrasi *template* AdminLTE untuk dasbor PENYEDIA dan ADMIN.
- [x] Setup struktur Bootstrap 5 & jQuery untuk halaman publik (PENYEWA).
- [x] Desain dan implementasi arsitektur Database MySQL (Migration/Seeder di CI4).

### Phase 1: Identity & Access Management (Sprint 2)
**Fokus**: Autentikasi dan pemisahan peran (Roles).
- [x] Registrasi & Login untuk PENYEWA dan PENYEDIA.
- [x] Manajemen profil dasar pengguna (Wajib mengisi *Gender* untuk kepatuhan Syariat).
- [x] Implementasi Role-Based Access Control (PENYEWA, PENYEDIA, ADMIN, SUPER ADMIN).
- [x] Manajemen Region (Country → Province → City).
- [x] Setup akses Backoffice untuk ADMIN dan SUPER ADMIN.

### Phase 2: Provider & Inventory Management (Sprint 3)
**Fokus**: Provider dapat mengelola properti mereka.
- [x] Alur *Onboarding* & *Verification* Provider.
- [x] Manajemen **Property** (Menetapkan `target_gender`: Putra/Putri/Keluarga sesuai Syariat).
- [x] Manajemen **Unit** dalam Property.
- [x] Pembuatan **Individual Listing** dari unit yang tersedia.
- [x] Integrasi ke Cloud Object Storage untuk *upload* gambar.

### Phase 3: Moderation & Discovery (Sprint 4)
**Fokus**: Kurasi listing oleh admin dan fitur pencarian bagi penyewa.
- [ ] Sistem moderasi *Listing* (Approval / Rejection dengan alasan) oleh Admin Daerah.
- [ ] Implementasi fungsi pencarian properti (Menggunakan *Query Builder* MySQL / *Full-Text Search*).
- [ ] Halaman Utama (Home) dan Hasil Pencarian (Search Results) dengan filter (lokasi, harga, dsb).
- [ ] Halaman Detail Listing (termasuk galeri dan harga sewa).
- [ ] Fitur *Favorite* untuk PENYEWA.

### Phase 4: Booking & Application Engine (Sprint 5)
**Fokus**: Proses transaksional pengajuan sewa.
- [ ] Form pengajuan sewa (Sistem menolak otomatis jika *Gender* penyewa tidak cocok dengan *Target Gender* properti).
- [ ] Dashboard PENYEDIA: Fitur *Review Application* (Terima/Tolak beserta validasi syarat Pasutri jika properti keluarga).
- [ ] State transition dari `PENDING` → `APPROVED` → pembentukan entitas `RESERVATION`.
- [ ] Konfigurasi timer kedaluwarsa (Expiration Window) untuk reservasi.
- [ ] Halaman *Checkout* dan kalkulasi harga (Rental Amount + Gateway Fee).

### Phase 5: Payment, WhatsApp & Contract (Sprint 6)
**Fokus**: Pembayaran, kontrak, dan pengingat via WhatsApp.
- [ ] Integrasi Payment Gateway (Checkout, Webhook untuk status `SUCCESS`/`FAILED`).
- [ ] Otomatisasi pembentukan `CONTRACT` ketika pembayaran berhasil.
- [ ] *State transition* Reservation → Rental Active.
- [ ] Integrasi **WhatsApp Business API** (Twilio/Qiscus/Meta) untuk notifikasi kritis:
  - Notifikasi *Payment Success*
  - Notifikasi *Application Approved/Rejected*
- [ ] Halaman detail Contract bagi PENYEWA dan PENYEDIA.

### Phase 6: Recurring Billing & Dashboard (Sprint 7)
**Fokus**: Siklus tagihan berkelanjutan dan visualisasi dasbor.
- [ ] Pembuatan sistem *Recurring Billing* (Invoices) berdasarkan jadwal pembayaran di kontrak.
- [ ] Worker (Cron Job) untuk mengubah status invoice dari `PENDING` → `OVERDUE` setelah *grace period* (3 hari).
- [ ] Notifikasi WhatsApp (H-3 jatuh tempo).
- [ ] Penyelesaian dasbor komprehensif untuk PENYEWA (Tagihan Aktif) dan PENYEDIA (Kapasitas Listing, Okupansi).
- [ ] Dasbor Backoffice (Audit Trail viewer, Disputes, Refund handling).

### Phase 7: Polish, QA & UAT (Sprint 8)
**Fokus**: Bug fixing, optimalisasi performa, dan rilis.
- [ ] Pengujian menyeluruh (End-to-End Testing) dari pencarian hingga pembayaran berulang.
- [ ] Load testing pada Endpoint pencarian & integrasi pembayaran.
- [ ] User Acceptance Testing (UAT) bersama pemangku kepentingan.
- [ ] Penetration Testing (Security audit) dasar.
- [ ] Persiapan peluncuran (Production Deployment) MVP.

### Phase 8: Upload Aplikasi & Deployment (Post-Sprint 8)
**Fokus**: Pemindahan aplikasi dari lingkungan lokal/staging ke server production untuk diakses publik. Tahap ini merangkum 2 skenario deployment:

**Skenario A: Upload Aplikasi ke cPanel (Shared Hosting)**
- [ ] Export Database lokal ke file `.sql`.
- [ ] Buat Database & User Database baru di MySQL Databases cPanel, lalu Import file `.sql`.
- [ ] *Zipping* file proyek CodeIgniter 4 (kecuali folder `vendor` jika ingin menjalankan `composer install` via terminal cPanel, atau *zip* seluruhnya).
- [ ] Upload *file zip* ke *File Manager* cPanel (ditempatkan di luar `public_html` untuk keamanan, misalnya di folder `sewakos_app`).
- [ ] Pindahkan isi folder `public` dari CodeIgniter 4 ke dalam folder `public_html`.
- [ ] Edit file `index.php` di dalam `public_html` agar *path* mengarah ke folder aplikasi `sewakos_app`.
- [ ] Edit file `.env`, ubah `CI_ENVIRONMENT = production`, sesuaikan `app.baseURL`, dan isi kredensial Database cPanel.
- [ ] Set up *Cron Jobs* di cPanel untuk mengeksekusi otomatisasi pengecekan tagihan `OVERDUE`.

**Skenario B: Upload Aplikasi ke VPS (Ubuntu / Debian Server)**
- [ ] Persiapkan VPS (Install Web Server Apache/Nginx, PHP 8.x, MySQL/MariaDB, dan Composer).
- [ ] Setup *Server Blocks* (Nginx) atau *Virtual Hosts* (Apache) yang mengarah ke direktori `public` proyek.
- [ ] Setup keamanan dasar (UFW Firewall, Install SSL/Certbot Let's Encrypt).
- [ ] *Clone* repositori Git aplikasi (Github/GitLab) langsung ke `/var/www/sewakos`.
- [ ] Jalankan `composer install` untuk mengunduh semua *dependencies*.
- [ ] Setup Database MySQL melalui command line dan jalankan `php spark migrate` serta `php spark db:seed`.
- [ ] Edit file `.env` untuk *environment* VPS (`CI_ENVIRONMENT = production`).
- [ ] Set up pengaturan *permission* folder yang benar (contoh: `chmod -R 775 writable/` dan `chown -R www-data:www-data writable/`).
- [ ] Konfigurasi *Cron Jobs* sistem operasi (`crontab -e`) untuk *background task*.

## 4. Prioritas & Scope Boundaries (Cut-off)

Untuk menjaga *timeline* MVP, beberapa fitur kompleks secara eksplisit ditunda ke Phase 2 (Post-MVP):
- Rekomendasi Pintar (*Smart Recommendations / AI*).
- Fitur Peta Interaktif Lanjutan (Bisa dimulai dengan versi sederhana).
- Sistem *Grouped Listing* (Satu listing banyak kamar identik).
- *Dynamic Pricing* & Diskon Promosi Komersial.
- *Subscription Billing* untuk Provider (MVP akan difokuskan pada free tier 6 bulan pertama, sistem *Listing Fee* disiapkan belakangan setelah *traction* tercapai).
